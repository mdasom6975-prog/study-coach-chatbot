# 커밋 메시지 작성

형식: `type(beta): 한국어 메시지`

- type은 feat, fix, docs, refactor, test, chore 중 하나다. 스코프는 항상 `beta`다.
- 메시지는 무조건 한국어로 쓴다. 영어 문장을 쓰지 않는다.

## cbea.ms 7규칙 (한국어 적용)

1. 제목과 본문 사이에 빈 줄을 둔다.
2. 제목은 50자 안팎으로 쓴다. (접두사 `type(beta): ` 포함)
3. 제목 끝에 마침표를 찍지 않는다.
4. 제목은 명령형으로 쓴다. 예: "추가한다", "고친다" 대신 "추가", "수정"처럼 간결한 동사형.
5. 본문은 72자 안팎에서 줄바꿈한다.
6. 본문은 "무엇을, 왜"를 쓴다. "어떻게"는 코드가 말해 준다.
7. 사소한 변경은 제목 한 줄로 끝낸다.

## 예시

```
feat(beta): 챗봇 답변에 과정 예시 추가

예시가 부족해 답변이 추상적이라는 피드백이 있었다.
과정 데이터에 예시를 12개로 늘려 답변 근거를 보강한다.
```

## 예외

- 시스템이 요구하는 `Co-Authored-By:` 줄은 영어 그대로 본문 끝에 붙인다.
