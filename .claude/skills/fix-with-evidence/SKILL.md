# 증거를 남기며 고치기

1. 재현: 실패를 보여 주는 명령을 정하고 실행한다. 출력의 핵심 줄을 그대로 적는다.
2. 원인: 원인 가설을 한 문장으로 적는다. 근거가 되는 파일과 줄을 적는다.
3. 수정: 원인 하나만 고친다. 범위 밖 파일은 바꾸지 않는다.
4. 재검증: 1번과 같은 명령을 다시 실행한다. 이어서 harness.config.json의 verify 명령을 실행한다.
5. 보고: 아래 형식으로만 보고한다.

## 지킬 것

- tests/, evals/ 안의 기준은 바꾸지 않는다. 기준이 틀렸다고 판단하면 수정 대신 근거를 보고한다.
- 실행하지 않은 검사를 통과로 적지 않는다.
